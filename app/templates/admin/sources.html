What the statuses mean

OK
The source was read successfully on the last refresh and its grants were added or updated automatically.
Monitored
The funder's page was reached, but it currently publishes no call that can be read as a grant (for example, a programme overview or a page built with JavaScript). It is checked automatically every refresh. Nothing is entered by hand.
Error
The last refresh could not read the source (site down, timeout). Its previous grants stay on the dashboard, and the next refresh tries again.
